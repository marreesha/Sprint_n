# Sprint_n

## Описание
Набор тестов для приложения Яндекс Маршруты:
- Отрисовка маршрута
- Отрисовка блока с выбором маршрута
- Подготовка к заказу такси
- Заказ такси
- Заказ такси полный флоу (Сценарий)

---

## Установка

1. Установка зависимостей:

```bash
pip install -r requirements.txt
```

2. Запуск теста:

```bash
pytest
```

3. Генерация отчета о тестировании:

```bash
allure generate allure_results --clean -o allure_report
```

4. Просмотр отчета:

```bash
allure open allure_report
```
